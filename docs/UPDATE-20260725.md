# Payroll Modern — Enhancement Update 2026-07-25

Dokumen ini menjelaskan cara memasang update pada repository dan database yang sudah digunakan. Update ini tidak membuat project baru, tidak memindahkan folder utama, dan tidak menghapus fitur maupun data lama.

## Urutan Pemasangan

1. Backup database Supabase dan repository GitHub.
2. Salin file baru/berubah dari paket patch ke repository yang sama dengan mempertahankan path-nya.
3. Jalankan `supabase/migration-20260725-payroll-enhancements.sql` melalui Supabase SQL Editor sebagai satu query.
4. Commit dan push perubahan ke branch yang terhubung ke Vercel.
5. Redeploy Vercel tanpa menggunakan Build Cache untuk deployment pertama setelah update.
6. Lakukan hard refresh browser setelah deployment selesai.

## Perubahan Database

Migration bersifat additive dan transaction-safe:

- menambah metadata soft delete pada `employees`;
- menambah metadata import pada `import_batches`;
- memperbarui view karyawan tanpa mengubah kolom lama;
- menambah RPC import karyawan, payroll, divisi, departemen, dan jabatan;
- menambah RPC arsip/pulihkan karyawan;
- menambah RPC duplicate, recalculate, bulk status, dan bulk delete payroll;
- memperbarui generate payroll agar mengabaikan karyawan yang diarsipkan;
- memperbarui dashboard summary dengan ringkasan karyawan, payroll, kehadiran, dan aktivitas terbaru;
- menambahkan audit log pada operasi massal.

Migration dibungkus `BEGIN`/`COMMIT`. Bila satu statement gagal, seluruh perubahan migration dibatalkan oleh PostgreSQL.

## Perbaikan Login

Auth provider sekarang menggunakan state bootstrap atomik, session restore tunggal, cache profil per session, single-flight fetch, dan generation guard. Route guard tidak lagi berganti antara halaman login dan dashboard selama profil sedang dipulihkan. Dashboard dipreload dan query awal diprefetch sebelum navigasi selesai.

## Internationalization

Bahasa tersedia:

- Bahasa Indonesia (`id`)
- English (`en`)
- Simplified Chinese (`zh-CN`)

Pilihan disimpan dengan key Local Storage `payroll-language`. Language switcher berada di header. Kamus utama berada di `src/i18n/messages.ts`; bahasa tambahan dapat dimasukkan tanpa mengubah komponen bisnis.

## Sidebar

Status collapse disimpan pada Local Storage `payroll-sidebar-collapsed`. Mode collapse menampilkan icon, tooltip, dan transisi lebar yang halus. Mobile drawer tetap bekerja terpisah.

## Import Massal

Template baru tersedia pada `public/templates`:

- `template-import-payroll.xlsx`
- `template-import-divisions.xlsx`
- `template-import-departments.xlsx`
- `template-import-positions.xlsx`

Import melakukan validasi dan preview di browser. Commit batch dilakukan melalui satu RPC Supabase sehingga kegagalan database membatalkan seluruh transaksi. Hasil menampilkan jumlah berhasil, gagal, dan dilewati.

## Soft Delete Karyawan

Tombol hapus pada modul karyawan sekarang mengarsipkan data. Tab Arsip menyediakan restore. Data lama dan payroll historis tidak dihapus. Karyawan terarsip tidak ikut generate payroll baru.

## Payroll Profesional

Fitur tambahan:

- import payroll transactional;
- duplicate payroll ke periode lain;
- recalculate payroll draft dari master kompensasi terbaru;
- regenerate token/QR slip pada payroll final atau dibayar;
- bulk finalisasi;
- bulk paid;
- bulk draft untuk memastikan ulang batch draft terpilih;
- bulk delete draft dengan konfirmasi.

Aturan lifecycle lama tetap dijaga oleh trigger database.

## Table dan Performa

Tabel utama mempunyai:

- column visibility tersimpan;
- resize kolom tersimpan;
- sticky header;
- multi-column sort dengan Shift + klik;
- pagination;
- content-visibility untuk mengurangi rendering row di luar viewport;
- pencarian debounce;
- export Excel, CSV, dan PDF sesuai konteks.

## Email Slip

Pengiriman email tidak diaktifkan karena project saat ini tidak mempunyai SMTP/provider email server-side. Preview, PDF, cetak, ZIP, Excel, dan CSV tetap tersedia. Tidak ada secret SMTP yang ditanamkan di frontend.

## Verifikasi Setelah Update

Periksa hal berikut:

1. Login tidak berkedip dan tidak reload halaman.
2. Language switcher bertahan setelah browser direfresh.
3. Sidebar collapse bertahan setelah login ulang.
4. Template import dapat diunduh.
5. Import preview menampilkan error per baris.
6. Import payroll gagal total bila database menolak satu baris.
7. Karyawan dapat diarsipkan dan dipulihkan.
8. Bulk payroll hanya mengubah status yang sesuai lifecycle.
9. Dashboard menampilkan recent activity dan ringkasan tambahan.
10. Vercel build memakai Node 22.x dan tidak memakai build cache lama.
