# Internationalization Architecture

## Bahasa dan Locale

```ts
type Locale = 'id' | 'en' | 'zh-CN';
```

Locale aktif disimpan pada Local Storage `payroll-language`. `I18nProvider` juga memperbarui atribut `lang` dan `dir` pada elemen `<html>`.

## File Utama

- `src/i18n/messages.ts`: kamus phrase, pola teks dinamis, nama locale, dan helper terjemahan.
- `src/i18n/I18nContext.tsx`: state locale, persistence, DOM translation bridge, dan API `t()`.
- `src/hooks/useTranslation.ts`: hook konsumsi konteks.
- `src/components/layout/LanguageSwitcher.tsx`: pemilih bahasa di header.

## Menambah Bahasa

1. Tambahkan locale pada union `Locale`.
2. Tambahkan nama locale pada `LOCALE_OPTIONS`.
3. Tambahkan kamus ke `DICTIONARIES`.
4. Tambahkan pola dinamis bila diperlukan.
5. Tambahkan test pada `src/tests/i18n.test.ts`.

## Translation Bridge

Komponen baru disarankan menggunakan `const { t } = useTranslation()` secara langsung. Untuk menjaga kompatibilitas semua komponen lama tanpa refactor destruktif, provider juga menerjemahkan text node dan atribut seperti `placeholder`, `title`, serta `aria-label` melalui MutationObserver. Mekanisme tersebut memungkinkan seluruh UI lama tetap mengikuti locale aktif sambil mempertahankan struktur dan alur bisnis.

## Pesan Dinamis

`translatePhrase()` mendukung placeholder angka seperti jumlah berhasil, gagal, dan dilewati. Pesan error Supabase yang umum dinormalisasi melalui `getErrorMessage()` sebelum ditampilkan sebagai toast atau error boundary.
